1.Physical Layer : 
-> it converts logical data into physical streams
->Interfaces hardware with the network
->Deals with the mechanical and electrical specifications
-> Converts data packets into bit streams to transfer them through the physical transmission media.


Agar aapko normal JavaScript, C++, ya Python file ke comments mein diagram rakhna hai, toh aap is ASCII art ko use kar sakte hain:

Function of Physical Layer:
-> Cable and Connectors(Guided and unguided)
-> Physical Topology (Tree, Bus, Star, Mesh)
-> hardware (Repeater, Hub)
-> Transmission mode (Simple, Duplex)
-> Multiplexing (FDM, TDM)
-> Encoding (Analogy, Digital)
