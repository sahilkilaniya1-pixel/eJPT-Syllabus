The Internet Protocol version 6
-> IPv6 was developed by internet Engineering Task Force (IETF) to deal with the  Problem of IPv4 exhaustion.
-> IPv6 is 128-bits address having an address space of 2^128, which is way bigger than IPv4. In IPv6 we use colon-hexa representation. there are 8 groups and each groups represents 2 Bytes.
-> in IPv6 representation, we have three addressing methds:
:: Unicast
::Multicast
::ANycast

Description: IPv6 address representation (128-bit Hexadecimal format), contiguous zero compression 
using double colon (::), aur Hex-to-Binary expansion ka complete breakdown.

----------------------------------------------------------------------------------------------------
🎨 IPv6 REPRESENTATION & COMPRESSION DIAGRAM
----------------------------------------------------------------------------------------------------

FULL HEXADECIMAL FORMAT (8 Hextets / 128 Bits):
  2001 : 0DB8 : AC10 : FE01 : 0000 : 0000 : 0000 : 0000
    │      │      │      │     └──────────┬───────────┘
    ↓      ↓      ↓      ↓                │ (Consecutive Zero Blocks)
  2001 : 0DB8 : AC10 : FE01 :: <──────────┴─ Zeroes can be omitted!

BINARY EXPANSION (16 bits per hextet):
  2001  ───>  0010 0000 0000 0001
  0DB8  ───>  0000 1101 1011 1000
  AC10  ───>  1010 1100 0001 0000
  FE01  ───>  1111 1110 0000 0001
  ::    ───>  0000000000000000:0000000000000000:0000000000000000:0000000000000000

----------------------------------------------------------------------------------------------------
📄 STEP-BY-STEP CONCEPT BREAKDOWN (Hinglish Notes)
----------------------------------------------------------------------------------------------------

1. IPv6 ADDRESS STRUCTURE & FORMAT:
   - IPv6 Address total **128 bits** ka hota hai.
   - Isko **8 groups (hextets)** mein divide kiya jata hai, aur har group mein 4 Hexadecimal digits (16 bits) hote hain.
   - Groups ko **Colons (:)** se alag kiya jata hai.

2. ZERO OMISSION RULE (Double Colon '::'):
   - Slide Text: "Zeroes can be omitted"
   - 💡 Hinglish Explanation: 
     * Jab IPv6 address mein ek se zyada continuously zero wale blocks (`0000:0000:0000:0000`) aayein, toh unhe short karne ke liye **Double Colon (`::`)** se replace kar diya jata hai.
     * Original: `2001:0DB8:AC10:FE01:0000:0000:0000:0000`
     * Compressed: `2001:0DB8:AC10:FE01::`
   - ⚠️ GOLDEN RULE FOR EXAMS:
     * Ek IPv6 address mein `::` (Double Colon) ko **sirf EK hi baar** use kiya ja sakta hai.
     * Agar do alag jagah par `::` lagaoge toh system decide nahi kar payega ki kis jagah kitne zero gayab hue hain!

3. HEXADECIMAL TO BINARY CONVERSION:
   - Har Hex digit 4 binary bits ke barabar hota hai ($4 \times 4 = 16\text{ bits per block}$):
     * `2` = 0010, `0` = 0000, `0` = 0000, `1` = 0001  ->  `0010000000000001`
     * `0` = 0000, `D` = 1101, `B` = 1011, `8` = 1000  ->  `0000110110111000`
     * `A` = 1010, `C` = 1100, `1` = 0001, `0` = 0000  ->  `1010110000010000`
     * `F` = 1111, `E` = 1110, `0` = 0000, `1` = 0001  ->  `1111111000000001`

->Unicast Address: Unicast Address identifies  a single network interface. A packet sent to unicast address is delivered to the interface identified by that address.

-> Multicast Address: Multicast address is used by Multiple hosts, called as Group , acquires a Multicast destination address. if any packet is sent to this multicast address, it will be destinated to all interface corresponding to that multicast address.

-> anycast Address: Anycast address is assigned to a group of interface. any packet sent to anycast address will be delivered to only one member interface (mostly nearest host possible). Updates routing tables.

NOTE:: Broadcast is not defined in IPv6.

🌐 IPv6 ADDRESS TYPES - UNICAST, MULTICAST & ANYCAST
====================================================================================================
Description: IPv6 Address Modes (One-to-One, One-to-Many, One-to-Nearest) ka complete breakdown, 
visual ASCII diagrams, aur real-world Hinglish explanations.

----------------------------------------------------------------------------------------------------
🎨 VISUAL DIAGRAM & TRANSMISSION MODES
----------------------------------------------------------------------------------------------------

1. UNICAST (One-to-One / Ek Se Ek):
      [ Sender ] ───────────────> [ Target Node ]
        (Red)                         (Green)
   - Data sirf EK specific destination node ko jata hai.

2. MULTICAST (One-to-Many / Ek Se Group):
                                ┌─> [ Target Node 1 ]
      [ Sender ] ───────────────┼─> [ Target Node 2 ]
        (Red)                   └─> [ Target Node 3 ]
   - Data ek specific Group ke sabhi member nodes (Green) ko jata hai.

3. ANYCAST (One-to-Nearest / Ek Se Sabse Paas Wala):
      [ Sender ] ───────────────> [ Closest Node ] (Nearest Green Node)
        (Red)                     (Other Green Nodes ignored based on routing distance)
   - Data multiple same-address nodes mein se SABSE PAAS wale node ko deliver hota hai.

----------------------------------------------------------------------------------------------------
📄 DETAILED BREAKDOWN OF IPv6 ADDRESS TYPES (Hinglish Notes)
----------------------------------------------------------------------------------------------------

1. UNICAST ADDRESS (One-to-One Communication):
   - 💡 Concept: Isme communication **Ek Sender se Ek Specific Receiver** ke beech hota hai.
   - 📌 Key Feature: Network par uniquely identifier single interface ka hota hai. Packet destination IP address padh kar direct ussi ek device par bheja jata hai.
   - 🏢 Real-World Example: Private Messaging, Web Browsing (tum aur ek specific web server).

2. MULTICAST ADDRESS (One-to-Many Communication):
   - 💡 Concept: Isme communication **Ek Sender se ek specific Group of Receivers** ke beech hota hai.
   - 📌 Key Feature: IPv6 mein **Broadcast Address feature KHATAM (Replace)** kar ke Multicast ko primary bana diya gaya hai. Sirf wohi devices packet process karte hain jo us multicast group ke part (Green) hote hain.
   - 🏢 Real-World Example: Live Video Streaming, Zoom Call, Routing protocol updates (OSPF/RIPng).

3. ANYCAST ADDRESS (One-to-Nearest Communication):
   - 💡 Concept: Isme same IP Address Multiple Servers/Nodes ko assigned hota hai. Data sender se nikalkar network par **SABSE PAAS (Nearest/Closest)** wale server par pahunchta hai.
   - 📌 Key Feature: Router routing metric/distance dekhta hai aur closest node tak packet bhejta hai.
   - 🏢 Real-World Example: CDN Services (Cloudflare/Akamai) aur DNS Root Servers (taaki user ko fastest response mile).
