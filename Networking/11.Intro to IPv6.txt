📄 1. INTRODUCTION TO IPv6 (IPv6 Kya Hai?)
----------------------------------------------------------------------------------------------------

- IPv6 ko **Internet Engineering Task Force (IETF)** ne develop kiya tha taaki IPv4 addresses ki kami (exhaustion problem) ko solve kiya ja sake.
- IPv6 ka address size **128-bits** hota hai, jiski total address space $2^{128}$ hoti hai (jo ki IPv4 ke $2^{32}$ se bohot zyada bada hai).
- IPv6 addresses mein **Colon-Hexadecimal Notation** ka use hota hai.
- Isme total **8 groups (hextets)** hote hain aur har group **2 Bytes (16 bits)** ko represent karta hai:
  $$\text{Total Size} = 8 \text{ groups} \times 2 \text{ Bytes} = 16 \text{ Bytes} = 128 \text{ Bits}$$

- **Addressing Methods:** IPv6 mein main 3 addressing methods hote hain:
  1. Unicast
  2. Multicast
  3. Anycast

🎨 2. IPv6 REPRESENTATION & COMPRESSION RULES (Zero Omission)
----------------------------------------------------------------------------------------------------

FULL HEXADECIMAL FORMAT (8 Hextets / 128 Bits):
  2001 : 0DB8 : AC10 : FE01 : 0000 : 0000 : 0000 : 0000
    │      │      │      │     └──────────┬───────────┘
    ↓      ↓      ↓      ↓                │ (Consecutive Zero Blocks)
  2001 : 0DB8 : AC10 : FE01 :: <──────────┴─ Zeroes can be omitted!

BINARY EXPANSION (16 bits per hextet):
  2001  ───>  0010 0000 0000 0001
  0DB8  ───>  0000 1101 1011 1000
  AC10  ───>  1010 1100 0001 0000
  FE01  ───>  1111 1110 0000 0001
  ::    ───>  0000000000000000:0000000000000000:0000000000000000:0000000000000000

----------------------------------------------------------------------------------------------------
💡 COMPRESSION & CONVERSION RULES EXPOSED
----------------------------------------------------------------------------------------------------

1. ADDRESS STRUCTURE:
   - IPv6 Address total 128 bits ka hota hai, jo 8 hextets mein split hota hai.
   - Har group colons (`:`) se divide hota hai aur har hextet mein 4 Hexadecimal digits hote hain.

2. ZERO OMISSION RULE (Double Colon '::'):
   - Jab IPv6 address mein ek se zyada continuously zero wale blocks (`0000:0000:0000:0000`) aayein, toh unhe short karne ke liye **Double Colon (`::`)** se replace kar diya jata hai.
   - Original: `2001:0DB8:AC10:FE01:0000:0000:0000:0000`
   - Compressed: `2001:0DB8:AC10:FE01::`
   
   ⚠️ GOLDEN RULE FOR EXAMS:
   - Ek IPv6 address mein `::` ko **sirf EK hi baar** use kar sakte hain. 
   - Agar 2 jagah par `::` lagaoge toh system zero count wapas reconstruct nahi kar payega!

3. HEXADECIMAL TO BINARY CONVERSION:
   - Har Hex digit 4 binary bits ke barabar hota hai ($4 \times 4 = 16\text{ bits per block}$):
     * `2001` ───> 0010 0000 0000 0001
     * `0DB8` ───> 0000 1101 1011 1000
     * `AC10` ───> 1010 1100 0001 0000
     * `FE01` ───> 1111 1110 0000 0001

🎨 3. IPv6 ADDRESSING MODES (Unicast, Multicast & Anycast)
----------------------------------------------------------------------------------------------------

VISUAL TRANSMISSION MODES:

1. UNICAST (One-to-One / Ek Se Ek):
      [ Sender ] ───────────────> [ Target Node ]
        (Red)                         (Green)
   - Data sirf EK specific destination interface/node ko deliver hota hai.

2. MULTICAST (One-to-Many / Ek Se Group):
                                ┌─> [ Target Node 1 ]
      [ Sender ] ───────────────┼─> [ Target Node 2 ]
        (Red)                   └─> [ Target Node 3 ]
   - Data ek specific Group ke sabhi member interfaces (Green) tak pahunchta hai.

3. ANYCAST (One-to-Nearest / Ek Se Sabse Paas Wala):
      [ Sender ] ───────────────> [ Closest Node ] (Nearest Green Node)
        (Red)                     (Other Green Nodes ignored based on routing distance)
   - Same address multiple nodes ko diya jata hai, par packet SABSE PAAS wale node ko milta hai.

----------------------------------------------------------------------------------------------------
📄 DETAILED TYPES BREAKDOWN
----------------------------------------------------------------------------------------------------

1. UNICAST ADDRESS (One-to-One):
   - Definition: Unicast Address single network interface ko uniquely identify karta hai.
   - Working: Jab kisi packet ko Unicast address par bheja jata hai, toh woh packet direct usi ek target interface ko deliver hota hai.
   - Example: Tumhare laptop aur web server ke beech ka direct communication.

2. MULTICAST ADDRESS (One-to-Many):
   - Definition: Jab multiple hosts milkar ek group banate hain, toh unhe ek Multicast destination address milta hai.
   - Working: Agar koi packet Multicast address par bheja jata hai, toh woh us group se judi saari interfaces par ek sath deliver hota hai.
   - Example: Live streaming, Zoom calls, Network updates.

3. ANYCAST ADDRESS (One-to-Nearest):
   - Definition: Anycast address multiple interfaces (nodes) ke group ko assign kiya jata hai.
   - Working: Koi bhi packet jab Anycast address par bheja jayega, toh routing tables ke acche management se woh sirf EK hi member interface ko deliver hoga—jo sender ke **sabse paas (nearest host)** hoga.
   - Example: DNS root servers, CDN services (Cloudflare/Akamai).

⚠️ NOTE FOR EXAMS:
   - IPv6 mein **Broadcast Address concept EXIST NAHI KARTA**. Broadcast ki saari zarurato ko Multicast ke dwara handle kiya jata hai.
