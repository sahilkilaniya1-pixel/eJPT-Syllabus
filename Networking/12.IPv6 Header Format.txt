----------------------------------------------------------------------------------------------------
🛠️ DETAILED BREAKDOWN OF IPv6 HEADER FIELDS (Hinglish Notes)
----------------------------------------------------------------------------------------------------

1. FIXED BASE HEADER (40 Bytes Total):
   - IPv6 ke base header ka size **hamesha fixed (40 Bytes)** hota hai. 
   - Isme 8 fields hote hain (IPv4 mein 12-14 fields hote the, isiliye IPv6 routers par fast process hota hai).

2. ROW 1: BASIC METADATA & QOS
   - Version (4 bits): IP Version batata hai. IPv6 ke liye iski fixed value binary mein `0110` (6) hoti hai.
   - Priority / Traffic Class (8 bits): IPv4 ke 'Type of Service (ToS)' ki tarah packets ki priority (Quality of Service - QoS) maintain karta hai.
   - Flow Label (20 bits): Real-time audio/video flows ko identify karne ke liye use hota hai taaki saare packets same router path se jayein aur delay na ho.

3. ROW 2: LENGTH, NEXT HEADER & LIFETIME
   - Payload Length (16 bits): IP Base Header (40 Bytes) ke baad kitna extra data + extension headers hain, unka size bytes mein batata hai.
   - Next Header (8 bits): IPv4 ke 'Protocol' field ki tarah kaam karta hai. Batata hai ki is header ke baad kaun sa Extension Header hai ya kaun sa Upper-Layer Protocol (TCP/UDP) aayega.
   - Hop Limit (8 bits): IPv4 ke 'TTL (Time To Live)' ki tarah kaam karta hai. Har router par yeh 1 se kam hota hai. Jab 0 ho jata hai, packet drop ho jata hai loop se bachne ke liye.

4. ROW 3 & ROW 4: ADDRESSES
   - Source Address (128 bits / 16 Bytes): Packet bhejne wale (Sender) ka complete 128-bit IPv6 Address.
   - Destination Address (128 bits / 16 Bytes): Packet receive karne wale (Receiver) ka complete 128-bit IPv6 Address.

5. EXTENSION HEADERS:
   - Extra options (jaise Fragmentation, Security/IPSec, Routing) ko base header mein rakhne ke bajaye **Extension Headers** ke form mein alag se chain kiya jata hai.

----------------------------------------------------------------------------------------------------
📊 IPv4 vs IPv6 HEADER DIFFERENCES (Exam Special)
----------------------------------------------------------------------------------------------------

+-----------------------+-----------------------+---------------------------------------------------+
| Feature               | IPv4 Header           | IPv6 Header                                       |
+-----------------------+-----------------------+---------------------------------------------------+
| Base Header Size      | Variable (20-60 Bytes)| **Fixed 40 Bytes**                                |
| Address Fields Size   | 32 bits (4 Bytes)     | **128 bits (16 Bytes)**                           |
| Lifetime Field Name   | Time To Live (TTL)    | **Hop Limit**                                     |
| Protocol Field Name   | Protocol              | **Next Header**                                   |
| Service Field Name    | Type of Service (ToS) | **Traffic Class**                                 |
| Header Checksum       | Present (16 bits)     | **Removed** (Lower/Upper layers par handle hota hai)|
+-----------------------+-----------------------+---------------------------------------------------+
