# 7. Computer Memory Hierarchy

| Storage Type | Typical Access Time | Relative Cost | Volatility |
| :--- | :--- | :--- | :--- |
| **CPU Registers** | < 1 ns | Highest | Volatile |
| **Cache (L1 / L2 / L3)** | 1 - 10 ns | Very High | Volatile |
| **Main Memory (RAM)** | 10 - 100 ns | High | Volatile |
| **SSD / NVMe** | 10 - 100 µs | Medium | Non-Volatile |
| **HDD (Hard Disk)** | 5 - 15 ms | Low | Non-Volatile |
