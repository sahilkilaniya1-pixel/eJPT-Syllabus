# 1. Memory Management Concepts

| Core Concept | Description |
| :--- | :--- |
| **Logical vs Physical Address Space** | **Logical (Virtual) Address** is generated by the CPU. **Physical Address** is the actual location in RAM. The **MMU (Memory Management Unit)** hardware handles dynamic address translation at runtime. |
| **Contiguous Allocation** | The entire process is loaded into a single, uninterrupted contiguous block of memory. |

---

## Partitioning & Fragmentation

| Allocation Scheme | Key Feature | Primary Issue / Fragmentation |
| :--- | :--- | :--- |
| **Fixed Partitioning** | Memory is divided into fixed-size partitions. | **Internal Fragmentation:** Unused allocated space remaining inside a fixed partition. |
| **Dynamic Partitioning** | Partitions are allocated dynamically based on process size. | **External Fragmentation:** Total free memory is sufficient, but no single continuous block is available. |

---

## Dynamic Allocation Strategies

| Strategy | Selection Criterion | Key Characteristics |
| :--- | :--- | :--- |
| **First Fit** | Allocates the first hole that is big enough. | Fastest allocation strategy. |
| **Best Fit** | Allocates the smallest hole that is big enough. | Leaves behind the smallest unusable leftover space. |
| **Worst Fit** | Allocates the largest available hole. | Leaves large leftover space for subsequent processes. |
